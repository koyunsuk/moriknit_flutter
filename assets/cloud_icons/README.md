# Cloud Provider Brand Icons

이 디렉토리에는 클라우드 카드에 표시될 브랜드 아이콘 PNG가 들어갑니다.

## 필요한 파일 (수동 추가)

| 파일명 | 권장 크기 | 사용처 |
|--------|----------|--------|
| `dropbox.png` | 256x256 (정사각) | Dropbox 카드 |
| `google_drive.png` | 256x256 (정사각) | Google Drive 카드 |
| `icloud.png` | 256x256 (정사각) | iCloud Drive 카드 |
| `onedrive.png` | 256x256 (정사각) | OneDrive 카드 |

## 다운로드 가이드

각 브랜드의 공식 프레스킷/브랜드 리소스 페이지에서 PNG 받아 위 파일명으로 저장:

- Dropbox: https://www.dropbox.com/branding
- Google Drive: https://about.google/brand-resource-center/logos-list/
- iCloud: https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html
- OneDrive: https://www.microsoft.com/en-us/microsoft-365/onedrive/online-cloud-storage (브랜드 가이드 준수)

## 코드 동작

PNG 파일이 없어도 카드가 깨지지 않고 기본 `Icons.cloud_*` 아이콘으로 fallback 표시됩니다.
PNG 파일을 추가하면 자동으로 브랜드 아이콘이 표시됩니다.

## 라이선스 주의

각 브랜드 가이드라인 준수 필수. 변형/색상 변경 금지인 브랜드가 있으니 공식 자산만 사용.
